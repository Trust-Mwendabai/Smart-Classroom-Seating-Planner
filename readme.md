Smart Classroom Seating Planner

The Smart Classroom Seating Planner is a frontend application that allows teachers or students to create and organize classroom seating arrangements interactively. Users can specify the number of rows and seats, add student names, and rearrange seats through an interactive interface.

Using HTML5, CSS3, and JavaScript, the system will dynamically generate the classroom layout and provide drag-and-drop functionality for moving students between seats. JavaScript can implement different seating strategies such as random allocation, alphabetical arrangement, group seating, and balanced distribution. The system can also identify empty seats and generate a printable seating chart. Student names and preferred layouts can be temporarily or persistently stored using Local Storage without a database.
